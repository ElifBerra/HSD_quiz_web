# HSD Quiz Web Application
Bu proje, Huawei Student Developers (HSD) topluluğu için özel olarak geliştirilmiş, dinamik bir test/quiz platformudur. Kullanıcılar sınavlara katılabilir, yöneticiler ise admin paneli üzerinden yeni testler, sorular ve kriterler oluşturabilir.

## 🚀 Proje Hakkında
HSD Quiz Web, .NET 8 ve modern web teknolojileri kullanılarak geliştirilmiş, gerçek zamanlı veritabanı yönetimi sunan bir web uygulamasıdır.

### Temel Özellikler
#### Dinamik İçerik Yönetimi: 
Admin paneli ile test başlıklarını, soruları ve cevapları kolayca düzenleme.

#### Modern Mimari: 
Loose coupling (gevşek bağlılık) prensibi ile event-driven (olay tabanlı) sistem tasarımı.

#### Veritabanı Entegrasyonu: 
Supabase/PostgreSQL altyapısı ve Dapper ORM ile yüksek performanslı veri işleme.

#### Responsive Tasarım: 
Mobil ve masaüstü cihazlarla tam uyumlu kullanıcı arayüzü.

### 🛠️ Kullanılan Teknolojiler
#### Backend: 
.NET 8 (ASP.NET Core Web API)

#### Frontend: 
HTML5, Tailwind CSS, JavaScript (Vanilla)

#### Veritabanı: 
PostgreSQL (Supabase üzerinden yönetilmektedir)

#### ORM: 
Dapper

#### Deployment: 
Railway.app & Vercel
